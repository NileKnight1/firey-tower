A game made with Godot

adapted from `Icy Tower`
THe game idea is simple, you have to keep jumping up wihtout letting the camera passes you.
You can fall safely, but only if it's in the camera borders, unless that, you lose

You can buy upgrade cosmetics, like player skin and monster skins!
You will gain bonus score if you jumped and landed perfectly many times in a row

# Controls:
- Move: A-D / left-right arrows
- Jump: space / enter / W /up arrow
